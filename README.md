# AquaFlow downloads

Official application downloads from **BoltXpert IT Agency**.

AquaFlow provides water-delivery and shop-management tools through two applications:

- **Manager (Host):** shop owners and managers.
- **Worker (Client):** delivery workers paired with their shop's Manager.

## Download

[View the latest release](https://github.com/boltxpert/aquaflow-downloads/releases/latest)

Each release includes versioned application files, installation notes and SHA-256
checksums. Choose the application for your role and read its release notes before
installing. The current release provides signed Android APKs.

## Protect your data

Back up Manager records and synchronize pending Worker work before updating.
If an update cannot be installed over your existing app, contact support before
uninstalling. Android may remove local application data during uninstall.
